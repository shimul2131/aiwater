Order Sync (ফোন + পিসি এক করা)

একবার সেটআপ করলে কাস্টমার ওয়েবসাইটে অর্ডার দিলে পিসি অ্যাডমিনেও দেখা যাবে।

  1. কম্পিউটারে cloud-orders.gs ফাইল খুলুন → সব কোড কপি করুন
  2. script.google.com → New project → কোড পেস্ট → Save
  3. Run → setup → Allow (একবার অনুমতি দিন)
  4. Deploy → New deployment → Type: Web app
  5. Execute as: Me · Who has access: Anyone → Deploy
    ⚠️ "Anyone with a Google account" দিলে Sync কাজ করবে না (লগইন পেজ আসবে)
  6. Web app URL (/exec) নিচে পেস্ট → Test Sync → সবুজ হলে Save → site-config.js আপলোড

URL সেট না করলে অর্ডার শুধু অর্ডারদাতার ফোনে থাকবে — পিসি অ্যাডমিনে আসবে না।
