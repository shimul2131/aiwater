Order Sync (phone + PC)

Once set up, website orders also show in PC admin.

  1. Open cloud-orders.gs on your computer → copy all code
  2. script.google.com → New project → paste code → Save
  3. Run → setup → Allow (one-time permission)
  4. Deploy → New deployment → Type: Web app
  5. Execute as: Me · Who has access: Anyone → Deploy
    ⚠️ Note: "Anyone with a Google account" will break Sync (login page)
  6. Paste Web app URL (/exec) below → Test Sync → if green, Save → upload site-config.js

Note: Without URL, orders stay only on the customer's phone — not on PC admin.

Steadfast Courier

Send confirmed orders in one click. Keys save on Google Apps Script only — not in the website files.

  1. Copy API Key & Secret Key from Steadfast Merchant portal
  2. Paste below → Save API Keys
  3. Orders → confirmed order → Steadfast API

Note: Keys are never shown again after save. Re-enter only if you need to update.
