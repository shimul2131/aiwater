# AI Water Controller — Landing Page

**FR Engineering Solutions** | aicontroller.store

## Files

- `index.html` — full Bangla landing page
- `style.css` — dark industrial IoT design
- `script.js` — mobile nav + WhatsApp helpers
- `assets/` — logo, product, sensor, app placeholders

## Run locally

```bash
npm run dev
```

Open http://localhost:5173

Or open `index.html` directly in a browser.

## Replace images

Put real photos in `assets/` and update `src` in `index.html`:

- `product-controller.png`
- `sensor.png`
- `app-screenshot.png`
- `logo.png`
